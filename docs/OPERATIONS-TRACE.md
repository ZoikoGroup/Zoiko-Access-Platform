# Cloud foundation and operations: the specification's 80 acceptance cases, checked against what is built

Written 2026-11-12 by the developer, from the specification's own acceptance cases. Each row is a judgement made by reading the case and the code, not an automatic result; "Met" means one of our own automated tests proves the behaviour. The cases have **not** been run as written. This is the developer's reading and nobody else has reviewed it.

**Totals: 5 met, 18 partly, 57 not built (of 80).**

What exists is request measurement with two indicators, key rotation, row-level isolation between customers and a go-live register that records a decision. The "not built" rows are the cloud itself: regional cells, infrastructure-as-code, key management service, backups and disaster recovery, a release pipeline, on-call and incident tooling. None of that can be built without a hosting decision and an operations team.
